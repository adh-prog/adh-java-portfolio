# Amal Dhaouadi — Java Backend Developer Portfolio

Portfolio statique responsive en HTML/CSS/JavaScript.

## Personnalisation avant publication

Dans `index.html`, remplacer :
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB`
- le lien GitHub du projet personnel
- éventuellement le texte d'expérience et les technologies selon le CV final.

## Ajouter le CV

Placer le CV dans `assets/cv.pdf`, puis ajouter un bouton dans la section hero :
`<a class="btn btn-secondary" href="assets/cv.pdf" download>Télécharger mon CV</a>`

## Publication sur GitHub Pages

1. Créer un repository GitHub, par exemple `amal-portfolio`.
2. Mettre `index.html`, `css/`, `js/` et `assets/` à la racine.
3. GitHub → Settings → Pages.
4. Choisir `Deploy from a branch`.
5. Sélectionner `main` et `/root`.
6. Enregistrer.

Le portfolio sera ensuite accessible via l'URL GitHub Pages fournie par GitHub.
